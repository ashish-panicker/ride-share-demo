Standalone API Tester

Use these interfaces to send HTTP requests to the Passenger and Ride services.

Passenger Service (Port 8081)

GET http://localhost:8081/api/passengers

GET http://localhost:8081/api/passengers/{id}

POST http://localhost:8081/api/passengers



PUT http://localhost:8081/api/passengers/{id}




Ride Service (Port 8082)

GET http://localhost:8082/api/rides

GET http://localhost:8082/api/rides/{id}

POST http://localhost:8082/api/rides
